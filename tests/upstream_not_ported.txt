# Upstream tests that the Python port does not run, with the reason.
#
# The registry of upstream tests is tests/upstream_registry.md, a copy of
# tests/registry.md in microsoft/playwright. scripts/check_test_registry.py checks
# that every test in it is ported to tests/async and tests/sync, or matches a rule
# here. One rule per line: a selector, then the reason. A selector is a test
# identifier (CH-017), a subsystem code (CG), or an upstream file glob without
# ".spec.ts" (library/unit/*). The checker fails on a rule that matches no test,
# and on a test that is ported and also matches a rule.

# Upstream internals, not the client API.
library/unit/*                      Unit tests of upstream internals.
library/events/*                    Tests the EventEmitter class of the Node.js client.
library/channels                    Checks the object tree of the Node.js client through its internals.
library/heap                        Measures the heap of the Node.js client.
page/page-leaks                     Counts server objects through toImpl(), which only the Node.js tests can reach.
library/role-utils                  Calls the injected script directly.
library/locator-parser              Tests the locator parser of the driver.
library/component-parser            Tests the component selector parser of the driver.
library/css-parser                  Tests the CSS selector parser of the driver.
library/locator-generator           Tests the locator generator of the driver.
library/selector-generator          Tests the selector generator of the driver.
library/coverage                    Checks the API coverage of the Node.js tests.
